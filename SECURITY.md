# Reporting Security Issues

This is an unaffiliated, brand-stripped fork. Report vulnerabilities in
**this fork's decoupling layer** privately via GitHub Security Advisories:

- Open the repository's **Security** tab → **Report a vulnerability**:
  <https://github.com/dwlf/pocket-casts-ios-fork-whitelabel/security/advisories/new>

Please allow us time to respond and ship a fix before disclosing the
issue publicly.

Vulnerabilities in the upstream podcast app itself (playback, sync,
downloader, parser, etc.) should be reported to the upstream project so
the fix reaches all consumers:
<https://github.com/Automattic/pocket-casts-ios/security>.
